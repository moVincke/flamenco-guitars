# Flamenco Guitars

A multilingual website dedicated to flamenco guitars, developed as a personal web project.

## Overview

This project was created to practice front-end development while working on a subject I am personally interested in: flamenco guitars.

The website allows users to browse different types and models of flamenco guitars, view detailed information, switch between multiple languages and choose between different visual themes.

## Features

- Multi-page website
- Dynamic content loaded with JavaScript and JSON
- Content loading using the Fetch API
- French, English and Dutch translations
- Multiple guitar types and models
- Multiple visual themes
- Persistent theme selection using Local Storage

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON
- Fetch API
- Local Storage
